Accessibility

WoafMeow is designed to be understandable and usable across devices, input methods, and changing abilities.

Accessible foundations

The website uses semantic headings, keyboard-accessible navigation, visible focus, descriptive image text, labeled forms, scalable type, reduced-motion support, and responsive layouts.

Ongoing review

Automated and manual checks cover keyboard use, zoom, contrast, screen-reader structure, image alternatives, and form errors.

Feedback

Use the Support page to report an accessibility problem or request help with any part of the website.
